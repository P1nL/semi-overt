# 首页开场

## 播放规则

- 只在整页载入首页（直接访问、书签、新标签页或刷新首页）时检查资格：距上次自动播放至少 2 小时，且滚动 24 小时内自动播放少于 2 次。不是自然日计数，午夜不清零；冷却结束也不会在当前页面突然播放。
- 使用 `localStorage` 的 `now.homeIntro.v2` 保存播放时间和主动跳过后的暂停期限，同源标签页共享；不再使用旧的会话内一次标记。正式开始播放前登记一次，刷新未播完的动画也不能绕过冷却；普通收尾及被频率限制的访问不会刷新记录。
- 点击“跳过动画”或按 Esc 后，立即退出并从跳过时刻暂停自动播放 24 小时。自然结束、接口失败、超时、切后台、尺寸变化及导航中止不追加这项暂停；已开始的播放仍计入次数。
- 站内返回首页、关闭文章浮层、切回标签页、浏览器前进／后退恢复及直接打开深链接不播放。后台载入的标签页直接显示页面，不占次数，也不在切到前台时补播；减少动态效果时不自动播放。
- 准备完成后再次核验最新记录；支持 Web Locks 时串行更新跨标签页记录，避免同时争抢播放资格。无法读取或写入存储时直接显示页面，不反复播放。
- 已保存的网站主题优先；无有效记录时跟随 `prefers-color-scheme`，不将系统兜底写成用户偏好。
- `prefers-reduced-motion: reduce` 直接显示页面。
- `Esc`、右下角“跳过动画”、播放中离开首页、进入后台或调整窗口尺寸均直接收尾。
- 符合播放资格时先保留浅／暗色遮罩，首页接口成功返回（含成功的空列表）、关键字体和布局都准备好后，才从 0ms 启动完整开场。不等待远程封面图片，也不要求服务器凑满 11 篇文章。
- 数据和字体并行准备；准备阶段最多等待 8 秒，接口最终失败、准备超时或布局／字体不可用时直接跳过。等待期间不显示骨架或加载文字，仍可通过“跳过动画”或 Esc 退出；晚到的数据不会重新触发开场。
- 完整动画仍为 12.76 秒，等待数据的耗时不计入动画时间。正式开播时重新设置 15.76 秒播放看门狗，避免慢请求截断后半段动画。HTML 挂载前的 8.5 秒兜底仅清除启动遮罩，不会终止已挂载的开场覆盖层。

## 统一时间线

时间常量位于 `src/features/home-intro/model/choreography.ts`，全部为真实毫秒。各段独立定速，不再整体等比例放慢。调试滑块也显示真实播放毫秒。

| 开始 | 内容 |
| --- | --- |
| 0 | 外圆描边与中心向两侧伸出的闭眼线 |
| 800 | 同一条眼裂连续撑成上下眼睑，790ms 内完成睁眼；同时复用主题切换的圆形揭幕几何与缓动 |
| 2240 | 覆盖层眼睛交给真实主眼睛，停顿 |
| 2550 | 视线上移 |
| 2880 | 首页按钮火花显现 |
| 3260 | 分类按钮从首页按钮位置快速吐出；首页与分类之间直接拉出实色液体连接，不做淡入 |
| 3350 | 第一次向右过冲拉伸时，小圆从轮廓上由零长出；之后保持轻微牵拉，液体连接颈逐渐拉细，不再追加第二次膨胀 |
| 4200 | 绿色自发光小圆脱离，沿直线先快后慢地移向右侧胶囊左端；分类按钮回弹 |
| 5380 | 小圆向右长成胶囊，图标逐个显现 |
| 6220 | 上弧字母由眼睛向外书写，字重归至 900 |
| 7480 | 下弧两端并行，每批间隔 360ms；最后恢复 O 与瞳仁 |
| 10160 | 超立方体先上升 |
| 10760 | 卡片开始入场，每张 800ms，通常间隔 120ms |
| 11510 | 超立方体到位 |
| 12760 | 最后一张卡片到位，移交常态交互与动画 |

卡片按测得的横向坐标排序，而非假设数据顺序等于视觉顺序。超立方体领先 600ms 起步；每张卡片保持固定 800ms 上升，不再为了同时结束而拖慢先出现的卡片。11 张卡片时错峰 120ms，更多卡片时压缩间隔以守住总时长。

## 调试

先执行 `npm run dev -- --host 127.0.0.1`。

- `/?intro=replay`：忽略冷却、次数及暂停记录重播，仅开发模式生效；不消耗自动播放次数，也不写入主动跳过的暂停记录。
- `/?intro=debug`：准备完后暂停；左下角时间滑块可以检查每个阶段；点击“播放”继续。
- 调试开关不会绕过用户的减少动态效果设置；生产构建忽略这些参数。

## 实现边界

- 只有一个 GSAP 主播放头；阶段内姿态由纯函数计算，可重复定位。
- 只将 Splash 的响应式播放进度更新限制为最高 60fps；复用局部帧预算，不修改全局 GSAP ticker 或其他动画。主时钟照常推进，每次允许更新时读取最新进度，不按固定帧数累加，因此总时长、阶段间隔和弹性节奏保持不变；低于 60fps 时不补算中间画面。完成、跳过与调试拖动直接同步，调试恢复播放时重置局部预算。
- 开场不改变常态页面尺寸、固定命中区域、超立方体投影和字体身份。
- 眼睛使用同一组件与几何；视线控制分别约束虹膜、瞳孔位移。
- 闭眼线不再交叉淡出切换图标：保持同一条可见轮廓，让上下眼睑以缓入缓出方式从中心撑开，眼角位置固定；眼白、虹膜和瞳孔由同一开口裁切露出。只对外圆线和紫色圆底进行外观渐变，完全睁开后与原眼睛轮廓一致。
- 下弧 emoji 使用真实字符占位之上的绝对定位覆盖层，继承完全相同的模糊、透明度与透视缩放；各字槽的 emoji 池相互独立，避免同帧和跨字槽重复。
- 分类按钮的真实命中区域不动：可视层从首页按钮位置快速吐出，向右过冲最大 28px；第一次形变时轮廓宽度超过常态的 1.6 倍、高度压到 0.7 倍以下，图标保持轻微等比缩放，不跟随轮廓挤扁。吐出主行程仍为 180ms，不追加第二次主要形变。
- 分类按钮只使用一次向右冲量：吐出开始后 90ms 同时启动形变与小圆生成，第一次过冲结束后持续放松，不再额外向右膨胀。液体细颈跟随实际轮廓，而不是连接到静止的布局边界；首页连接也跟随分类轮廓的缩放，不单独淡入。
- 入场期间不渲染分类菜单的收起圆形节点，避免按钮移动后露出静止小点；常态菜单行为不变。
- 左侧导航图层固定为：首页按钮在最上层，分类按钮整体（包括轮廓和图标）在其下，液体连接在最底层；吐出重叠时首页圆盘保持完整遮挡。
- 小圆分离总时长为 850ms：保留最初 174.4ms 的长出过程，将随后连接拉细断开从 915.6ms 缩短至 675.6ms。断开及其后所有时点整体提前 240ms，不留下额外停顿；直线移动仍为 1180ms，刚脱离时最快，随后持续减速。小圆从零半径长出，直径约 23–25px，圆形自身呈绿色发光，不再使用白色外光晕；长成胶囊时发光逐渐退去。
- 上弧笔画遮罩使用现有 OFL Roboto Flex 字体的真实细字重轮廓。修改标题字母集合后，维护笔画数据并执行 `python scripts/generate-intro-glyphs.py`（需要本机 fonttools，仅生成资产时需要）。
- 首页页面通过内部就绪信号通知开场；等待接口成功及 DOM 更新后再锁定真实卡片集合、测量位置并启动时间线。卡片数据未就绪或列表为空时底部完全留空，不渲染骨架、占位条或加载文字。主动跳过或超时后返回的数据只正常显示，不补播开场，也不改卡片位置。
- 首页不再调用开发假文章补位。桌面端有真实文章但不足 11 张时，用无标题、无链接、不可聚焦的装饰片补足；装饰片在左，真实文章在右，开发与生产逻辑一致。Splash 结束后，鼠标直接悬停装饰片也会触发与真实卡片相同的抬升、相邻侧推／倾斜、阴影和离开回弹；只有真实文章卡可以点击跳转。
- 装饰片与真实卡片共用整卡升起时间线，标题不增加单独动效。保留原卡片位置、尺寸、错层、重叠间距及图层顺序；只在布局变化时根据不受动画影响的槽位坐标分配内容，适配原布局可能存在的正向或反向排列，不用修改间距来实现排序。窄屏列表只展示真实文章，不插入空白卡片；完全无文章时底部留空。

## 验证

```sh
node --experimental-strip-types --test scripts/home-intro.test.mjs scripts/home-intro-lifecycle.test.mjs scripts/home-intro-frequency.test.mjs scripts/category-intro-motion.test.mjs scripts/header-seed.test.mjs scripts/snoopy-eye.test.mjs scripts/animation-budget.test.mjs scripts/title-orbit.test.mjs scripts/tesseract.test.mjs scripts/scramble-text.test.mjs
npm run build
git diff --check
```

浏览器检查至少包含浅暗主题、桌面和窄屏、阶段顺序、跳过、会话内不重播、减少动态效果，以及接口失败时收尾。
