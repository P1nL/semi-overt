# 页面手动回归脚本

> 更新：2026-10-11。此文档是待执行的验收步骤，不是已通过报告。自动测试不能替代浏览器验收。

## 准备

启动匹配当前 API 的后端与前端，准备 USER、ADMIN 和多篇可操作的测试文章。保留正常浏览器数据，另用隔离会话验证首次访问；不要为了测试清空真实用户数据。

建议记录桌面 ≥1024px、390px 窄屏、浅/暗主题和减少动态效果四类条件。移动端软键盘与触摸行为需要真机，不以缩小桌面窗口代替。

## 1. 访客、首页与阅读

- 首次符合条件访问首页：等待数据/字体就绪再播放开场；Esc 或跳过后立即可交互。
- 刷新、重复访问、站内返回、切后台、调整尺寸：按 [首页开场规则](home-intro.md) 收尾，不意外补播。
- 首页没有文章时不伪造文章；桌面装饰卡不可点击，窄屏不添加空白卡片。
- 分类、文章搜索、作者搜索与 URL 同步；覆盖空结果、失败、分页和快速更换关键词。
- 结果卡片/列表切换后内容与点击目标一致，不能存在旧画面覆盖。
- 打开文章 Sheet：正文、目录、图片与代码块正常；关闭后背景位置保留，不重播背景入场。
- 不存在或不可见文章应有可理解的反馈，不因公开阅读失败而强制登录。

## 2. 注册与设备会话

- 错误密码留在表单；正常登录更新导航用户态。
- 注册邮箱验证码与 Turnstile 按部署配置工作；找回和重置密码错误可恢复。
- 直接访问受保护路由：显示登录入口；登录后恢复原目标。
- 刷新页面可通过 Cookie 恢复会话，检查浏览器存储没有持久化 access token。
- 多标签页登录/刷新/退出保持一致；并发过期请求不产生刷新风暴。
- 临时断网与会话真正过期分别反馈；退出失败不能被静默当成成功。

## 3. 编辑与写作箱

- 从新建入口进入 /article-editor-new，输入标题、摘要和正文，等待自动保存；确认保存状态与服务端一致。
- 首次创建后进入 /editor/:id；刷新恢复内容。测试离开未保存编辑器时的提示。
- 检查富文本格式、链接、图片、表格与 Markdown 相关操作，不丢失正文内容。
- 写作箱包含 DRAFT、PENDING、RETURNED；预览、继续编辑、删除及状态提示准确。
- 使用测试文章删除，验证列表与编辑态同步；已发布/拒绝内容不混入写作箱。
- 提交进入 PENDING；取消审核后按响应更新；不允许的动作有禁用或错误反馈。

## 4. 审核与个人主页

- ADMIN 打开 /review 和 /review/articles/:id；USER 访问同一路径应被拦截到 /403。
- 分别用三篇待审文章测试通过、退回和拒绝；需理由的动作填写理由后才提交。
- 操作后待审队列、日志与文章状态同步，冲突时不得展示虚假成功。
- 公开主页文章、资料、写作日历及可见统计正常；头像和封面失败时有回退。
- 编辑本人头像、封面和签名后，导航与主页同步；他人资料不能被编辑。

## 5. 视觉与生命周期

- 浅暗主题切换后刷新保持用户选择；未选择时检查系统主题兜底。
- 桌面首页 ↔ 结果 ↔ 主页，包含主页 A → B、快速二次导航、慢图片/慢接口。
- 动画中打开/关闭浮层、返回/前进，不残留遮罩、inert、滚动锁和不可点击区域。
- 减少动态效果下保留可理解的短过渡，不强行播放完整编排。
- 窄屏检查导航折叠、长标题、正文溢出、触摸操作、安全区和软键盘；不要求播放桌面转场。
- 菜单关闭后焦点与点击可恢复；错误/成功反馈可读。

完整动效约束见 [页面转场](page-transitions.md)。隔离假数据只能验证对应 UI，不证明真实登录、写入或生产后端可用。

记录浏览器/设备、视口、代码版本、后端版本、角色、场景和结果。通过应满足：无白屏/无限等待；核心创作审核链路可用；权限和错误策略正确；导航后无残留状态。未执行的项标记“未验证”，不要默认为通过。
